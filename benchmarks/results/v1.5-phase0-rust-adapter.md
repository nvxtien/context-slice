## Symbol coverage (this phase only)

Deliberately NOT yet indexed (deferred): macros, closures, tests as a distinct category, use/import records, generics/where-clause detail beyond raw signature text, Cargo workspace structure.

## Regression verification
- Test suite: 91 passed (see v1.5-phase0-baseline-replay.md)
- Java / TypeScript / Python: see v1.5-phase0-baseline-replay.md — all deltas versus the v1.4 Phase 0 report are 0.

## Why zero regression is expected
The Rust adapter only claims `.rs` files (via `adapterFor`'s extension-matching in `src/languages/adapter.ts`), so it cannot affect how Java/TypeScript/Python files are parsed, resolved, or composed. `resolveCalls` is a no-op, so no Rust call edges exist to interact with anything else.
