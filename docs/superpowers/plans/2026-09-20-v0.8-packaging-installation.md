# ContextSlice v0.8 Packaging and Installation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Produce a publish-ready npm tarball that works outside the source checkout and document an honest clean-room developer trial.

**Architecture:** Keep runtime code self-contained in `dist/src`, use package-relative version/asset resolution, and restrict the npm package to intentional runtime files. Exercise packaging through one fail-fast smoke runner that installs the tarball into a temporary npm prefix, uses a Java repository with spaces in its path, performs CLI/MCP/upgrade/uninstall checks, and writes machine-readable and human-readable reports.

**Tech Stack:** TypeScript, Node.js child processes, npm pack/install, existing CLI/MCP, SQLite cache, Node test runner.

**Spec:** `docs/prompt/CONTEXTSLICE_V0.8_PACKAGING_INSTALLATION_REAL_DEVELOPER_TRIAL.md`

## Global Constraints

- Do not publish to npm; only run `npm publish --dry-run`.
- The installed tool must not depend on source-checkout paths or current working directory for package assets.
- Runtime package must include compiled JS, package metadata, CLI/MCP code, query assets, README, and license.
- Keep v0.6/v0.7 correctness unchanged: full tests, build, benchmark:v06, benchmark:v07.
- Report telemetry as unavailable unless actually provided; do not call self-trial a multi-user study.
- Commit messages remain short and contain no Co-authored-by lines.

## Review Focus

- Installed binary invoked from a nested cwd must resolve its package version and nearest repository independently of cwd — test in package smoke runner.
- Tarball must not silently omit `queries/` or runtime entry points — assert required tarball members.
- Reinstall/upgrade must preserve a repository cache while incompatible schema handling remains automatic — test status/preview after reinstall.
- MCP started through only `context-slice mcp` must emit protocol-only stdout — reuse a packaged stdio request in the smoke runner.
- Paths containing spaces and isolated npm prefixes must not leak shell assumptions — use explicit child-process arguments and assert CLI results.
