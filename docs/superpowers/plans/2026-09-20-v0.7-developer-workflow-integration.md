# ContextSlice v0.7 Developer Workflow Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the existing Java ContextSlice engine installable, inspectable, and usable through a read-only developer CLI and stable MCP command.

**Architecture:** Add a small workflow layer around `ProjectIndex` for repository discovery, index freshness, deterministic preview construction, and user-facing errors. Keep the CLI as a zero-dependency argument parser, have MCP refresh before each tool call, and isolate workflow benchmarking from product behavior.

**Tech Stack:** TypeScript, Node.js standard library, existing `ProjectIndex`, SQLite cache, MCP SDK, Node test runner, `tsx`.

**Spec:** `docs/prompt/CONTEXTSLICE_V0.7_DEVELOPER_WORKFLOW_INTEGRATION.md`

## Global Constraints

- Keep Java-only parsing and do not add JDT/LSP, embeddings, vector storage, cloud services, GUI, hidden LLM calls, automatic editing, or multi-language support.
- Product preview/MCP paths may read only task text, repository content, index, and configuration; they must never read benchmark answers, required facts, expected symbols, or manual baselines.
- CLI preview, search, symbol, callers, status, and doctor are read-only except for `.context-slice` cache/index updates.
- Preview must not silently exceed its requested token budget; omitted context must carry a reason.
- MCP stdio diagnostics must never pollute stdout.
- Use deterministic token estimation and label token counts as estimated.
- Keep V0.6 correctness behavior intact and generate V0.7 workflow reports in JSON and Markdown.

## Review Focus

- Running from a nested directory must choose the nearest Git repository rather than the process directory.
- A target whose body exceeds budget must return `BUDGET_TOO_SMALL` without emitting oversized context.
- Editing one Java file after indexing must produce a stale state and an incremental refresh, not silently stale output.
- MCP tool execution must refresh before querying while emitting only protocol data on stdout.
- CLI user errors must have stable code, remediation, JSON shape, and non-zero status without stack traces by default.
